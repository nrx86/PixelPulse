# LensLab

LensLab is an image-search app that will allow users to search for a topic and display images related to their search. I chose a forest/earthy color theme because the app focuses on earthy elements and nature, giving it a calm and natural feel. I used orange as the main accent color because it blends well with the earthy theme while making important buttons and actions more attractive and noticeable. I also added quick-pick category buttons so users can easily explore popular topics without having to type a search every time.
