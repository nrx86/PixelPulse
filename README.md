# LensLab

LensLab is an image-search app that allows users to search for a topic and view images related to their search. The app uses a forest and earthy color palette because its visual identity is inspired by nature, creating a calm and natural experience. I chose orange as the main accent color because it contrasts with the earthy background and makes important actions such as buttons more noticeable. I also added quick-pick category buttons for topics like Nature, Cities, Animals, and Space so users can explore common topics quickly without having to type a search.
